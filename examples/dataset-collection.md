# Example: dataset collection

User asks: "Collect a dataset of public AI research tools with website, license, GitHub repo, and use case."

Expected skill behavior:
1. Define unit of observation as one tool/project.
2. Define fields and deduplication key.
3. Search broad and official sources.
4. Open official pages and repositories.
5. Extract public metadata.
6. Record blocked or uncertain sources.
7. Return CSV/JSON plus evidence ledger and data dictionary.
