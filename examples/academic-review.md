# Example: academic review

User asks: "Help me write a literature review on web scraping methods for dynamic websites."

Expected skill behavior:
1. Define research questions.
2. Build search strings.
3. Search papers, official docs, and technical reports.
4. Screen sources with inclusion/exclusion criteria.
5. Use snowballing from key papers.
6. Build evidence table.
7. Synthesize methods, limitations, trends, and future work.
