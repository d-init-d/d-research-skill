# D Research v3.6.0-rc.3

## v3.6.0-rc.3 Release Notes

This signed release-preparation snapshot includes the future stable 3.6.0
release notes in the frozen package inventory. Runtime behavior, dependencies,
and search/browser implementation are unchanged from v3.6.0-rc.2.

Candidate metadata and the promotion contract now bind to v3.6.0-rc.3. The
stable publication must still pass exact-commit CI, signed-tag verification,
metadata/path freeze checks, source reproduction, and provenance attestation.
No independent live host benchmark is claimed.

See [stable release notes](release-v3.6.0.md) for the feature overview,
compatibility, migration instructions, and operating limits. This preparation
tag is not itself the stable release.
