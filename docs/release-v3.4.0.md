# D Research v3.4.0

## v3.4.0 Release Notes

D Research v3.4.0 is the planned stable promotion of the v3.4.0-rc.1
monotonic-capability candidate. The stable tag is publishable only after the
exact candidate and stable commits, signed annotated tags, CI runs, artifact
checksums, extracted-profile self-tests, and provenance evidence have been
bound by the release gate.

The finalized stable record will describe the verified API expansion, archival
and metadata redaction fixes, downstream interop contract, direct reference
routing, and deterministic `full`/`runtime` artifacts from the promoted tree.
Until that evidence exists, use
[`release-v3.4.0-rc.1.md`](release-v3.4.0-rc.1.md) as the candidate contract;
this document makes no pre-publication release claim.
