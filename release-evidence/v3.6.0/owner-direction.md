# Stable publication direction

The repository owner requested publication of both upgraded skills and then
explicitly directed: **push thành bản chính thức luôn**. The later direction
**anti đã test nhiều rồi** asks to reuse valid existing verification and avoid
unnecessary repetition. These are standing task authorizations.

The published v3.6.0-rc.2 implementation already existed when this direction
was received. The derived rc.3 snapshot only freezes stable documentation,
package paths and candidate-binding metadata; runtime implementation is unchanged.
The override authorization timestamp records the release agent applying that
standing owner direction after the mandatory candidate checks. It does not
assert a new user message or independent human review after rc.3 creation.

Full exact-commit CI, signed annotated tags, semantic/path freeze checks,
source reproduction and provenance attestation remain required. Only the
repository contract's independent reviewer and live dogfood requirements are
waived under the owner's scoped promotion instruction. Automated agent checks
are not independent human approval or an empirical research benchmark.
